# VS-Code UI

A simple VS-Code inspired landing page built using HTML and CSS.

## Tech Stack

- HTML5
- CSS3
- SVG

## Features

- Clean and minimal landing page
- Zerodha-inspired UI
- Custom SVG assets
- Responsive layout

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mukul312004/vscode-landing.git
```
Open the project folder and launch index.html in your browser.
